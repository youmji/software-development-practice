# 4주차 - Bash 셸 스크립트 실습

## 1. 실습 목표
- Bash 셸 스크립트의 기본 구조 이해
- echo 명령어를 사용하여 메시지 출력
- 작성한 셸 스크립트 실행 및 결과 확인

## 2. 실습 환경
- WSL Ubuntu
- Bash

## 3. 실습 코드
파일명: backup.sh

```bash
#!/bin/bash
echo "로그 기록 성공"
```

## 4. 실행 방법
```bash
bash backup.sh
```

## 5. 실행 결과
```text
로그 기록 성공
```

## 6. 학습 내용
- #!/bin/bash는 Bash로 스크립트를 실행하도록 지정하는 구문.
- echo는 터미널에 문자열을 출력하는 명령어.
- bash backup.sh 명령어로 스크립트를 실행할 수 있음.

## 7. 실습 정리
backup.sh 파일을 실행하여 메시지가 정상적으로 출력되는 것을 확인. 
현재 코드는 실제 백업 기능이 아닌 출력 기능만 수행.
